## ReportV2

Mock report payload model for Data Streams report version 2.

**Kind**: global class

<a name="new_ReportV2_new"></a>

### new ReportV2(params)

| Param                        | Type                                       | Description                                     |
| ---------------------------- | ------------------------------------------ | ----------------------------------------------- |
| params                       | <code>object</code>                        | Report fields.                                  |
| params.feedId                | <code>string</code>                        | Feed identifier as bytes32 hex string.          |
| params.validFromTimestamp    | <code>number</code>                        | Earliest timestamp where the report is valid.   |
| params.observationsTimestamp | <code>number</code>                        | Latest timestamp covered by observations.       |
| params.nativeFee             | <code>bigint</code> \| <code>number</code> | Verification fee in native token units.         |
| params.linkFee               | <code>bigint</code> \| <code>number</code> | Verification fee in LINK units.                 |
| params.expiresAt             | <code>number</code>                        | Expiration timestamp for on-chain verification. |
| params.benchmarkPrice        | <code>bigint</code> \| <code>number</code> | Median benchmark price.                         |

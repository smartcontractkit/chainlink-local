## ReportV1

Mock report payload model for Data Streams report version 1.

**Kind**: global class

<a name="new_ReportV1_new"></a>

### new ReportV1(params)

| Param                        | Type                                       | Description                                           |
| ---------------------------- | ------------------------------------------ | ----------------------------------------------------- |
| params                       | <code>object</code>                        | Report fields.                                        |
| params.feedId                | <code>string</code>                        | Stream identifier as bytes32 hex string.              |
| params.observationsTimestamp | <code>number</code>                        | Observation timestamp in seconds.                     |
| params.benchmarkPrice        | <code>bigint</code> \| <code>number</code> | DON consensus median benchmark price.                 |
| params.bid                   | <code>bigint</code> \| <code>number</code> | Bid-side price estimate.                              |
| params.ask                   | <code>bigint</code> \| <code>number</code> | Ask-side price estimate.                              |
| params.currentBlockNum       | <code>bigint</code> \| <code>number</code> | Current block number used by the report.              |
| params.currentBlockHash      | <code>string</code>                        | Current block hash as bytes32 hex string.             |
| params.validFromBlockNum     | <code>bigint</code> \| <code>number</code> | Earliest block number from which the report is valid. |
| params.currentBlockTimestamp | <code>bigint</code> \| <code>number</code> | Current block timestamp in seconds.                   |

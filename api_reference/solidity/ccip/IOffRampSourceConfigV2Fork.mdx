# Solidity API

## IOffRampSourceConfigV2Fork

**Title:** IOffRampSourceConfigV2Fork

Minimal view/update surface for the CCIP 2.0 OffRamp per-source-chain config,
including the CCV sets used to verify messages. Mirrors
`OffRamp.SourceChainConfig`.

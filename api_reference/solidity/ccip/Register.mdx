# Solidity API

## Register

**Title:** Register Contract

This contract allows storing and retrieving network details for various chains.

Built-in network details are returned by a generated pure function (see
`helper_doc/updateRegisterContract.cjs`) instead of being written to storage in
the constructor: storing ~150 chains cost ~24M gas, which made
`CCIPLocalSimulatorFork` too expensive to deploy on 30M-gas-limit forks.
`setNetworkDetails` overrides are stored.

## State Variables

### s_networkDetails

Network details set with `setNetworkDetails`, overriding the built-in ones.

```solidity
mapping(uint256 chainId => NetworkDetails) internal s_networkDetails
```

### s_isOverridden

Whether `setNetworkDetails` was called for a chain ID.

```solidity
mapping(uint256 chainId => bool isOverridden) internal s_isOverridden
```

## Functions

### getNetworkDetails

Retrieves network details for a given chain ID.

```solidity
function getNetworkDetails(uint256 chainId) external view returns (NetworkDetails memory networkDetails);
```

**Parameters**

| Name      | Type      | Description                                   |
| --------- | --------- | --------------------------------------------- |
| `chainId` | `uint256` | - The ID of the chain to get the details for. |

**Returns**

| Name             | Type             | Description                                       |
| ---------------- | ---------------- | ------------------------------------------------- |
| `networkDetails` | `NetworkDetails` | - The network details for the specified chain ID. |

### setNetworkDetails

Sets the network details for a given chain ID.

```solidity
function setNetworkDetails(uint256 chainId, NetworkDetails memory networkDetails) external;
```

**Parameters**

| Name             | Type             | Description                                              |
| ---------------- | ---------------- | -------------------------------------------------------- |
| `chainId`        | `uint256`        | - The ID of the chain to set the details for.            |
| `networkDetails` | `NetworkDetails` | - The network details to set for the specified chain ID. |

### \_defaultNetworkDetails

Built-in network details for `chainId`, or an all-zero struct for an unknown
chain.

```solidity
function _defaultNetworkDetails(uint256 chainId) internal pure returns (NetworkDetails memory);
```

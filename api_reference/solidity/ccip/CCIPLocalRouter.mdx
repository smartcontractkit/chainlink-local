# Solidity API

## CCIPLocalRouter

**Inherits:** IRouter, IRouterClient

**Title:** CCIPLocalRouter

Local-mode router used by `CCIPLocalSimulator`. Mirrors `MockCCIPRouter` from
`@chainlink/contracts-ccip` 2.0.0 (same ABI, events and behaviour) and
additionally applies the CCIP 2.0 finality rules of the OnRamp and OffRamp, so a
test that passes locally does not fail on a fork or in production:

- the requested finality of `GenericExtraArgsV3` must use a single mode (OnRamp
  check at send time);
- a Faster-Than-Finality message that is not a token-only transfer is only
  delivered to a receiver whose `getCCVsAndFinalityConfig` allows the requested
  finality (OffRamp check). Receivers without `IAny2EVMMessageReceiverV2` accept
  finalized messages only.

`MockCCIPRouter.ccipSend` is not virtual, and wrapping it would change
`msg.sender`, hence the mirror.

### ccipSend

Sends the tx locally to the receiver instead of on the destination chain.

Ignores destinationChainSelector

Returns a mock message ID, which is not calculated from the message contents in
the same way as the real message ID.

```solidity
function ccipSend(uint64 destinationChainSelector, Client.EVM2AnyMessage calldata message)
    external
    payable
    returns (bytes32);
```

### \_isTokenOnlyTransfer

Same token-only rule as OffRamp 2.0 `_isTokenOnlyTransfer`, which also decides
whether the receiver is called.

```solidity
function _isTokenOnlyTransfer(uint256 dataLength, uint256 gasLimit, address receiver) internal view returns (bool);
```

### \_ensureReceiverAllowsFinality

OffRamp 2.0 `_getCCVsFromReceiver` finality check. Token-only transfers skip it,
as the pool enforces finality for them in production (pools are not simulated in
local mode).

```solidity
function _ensureReceiverAllowsFinality(
    address receiver,
    Client.Any2EVMMessage memory message,
    uint256 gasLimit,
    bytes4 requestedFinality
) internal view;
```

### \_parseExtraArgs

```solidity
function _parseExtraArgs(bytes calldata extraArgs)
    internal
    pure
    returns (uint256 gasLimit, bytes4 requestedFinality);
```

**Returns**

| Name                | Type      | Description                                                                        |
| ------------------- | --------- | ---------------------------------------------------------------------------------- |
| `gasLimit`          | `uint256` | Callback gas limit.                                                                |
| `requestedFinality` | `bytes4`  | `GenericExtraArgsV3.requestedFinalityConfig`, or WAIT_FOR_FINALITY for older tags. |

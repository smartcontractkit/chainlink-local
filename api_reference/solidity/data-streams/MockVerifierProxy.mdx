### \_validateBillingMechanism

Validates billing mechanism configuration and provides helpful error messages

This validation helps developers catch billing mechanism mismatches early in
development

```solidity
function _validateBillingMechanism(address feeManagerAddress, bytes calldata parameterPayload) internal pure;
```

**Parameters**

| Name                | Type      | Description                                                   |
| ------------------- | --------- | ------------------------------------------------------------- |
| `feeManagerAddress` | `address` | Current fee manager address (address(0) if off-chain billing) |
| `parameterPayload`  | `bytes`   | The parameter payload from the consumer contract              |
